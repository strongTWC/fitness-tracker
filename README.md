# FitCheck

แอปเช็คอินสถานที่ออกกำลังกาย พัฒนาด้วย React และ Vite

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

## สร้างไฟล์สำหรับ production

```bash
npm run build
npm run preview
```

หน้าเช็คอินรองรับการค้นหาและเลือกสถานที่ การเช็คอินเพื่อรับคะแนน และการขอตำแหน่งจากเบราว์เซอร์ (ต้องอนุญาต Location) ข้อมูลกิจกรรมในตัวอย่างเก็บใน state ของหน้าเว็บ
